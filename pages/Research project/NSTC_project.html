大語言模型應用於詐騙偵測之研究

延續「騙局雷達」經驗，以 LLM 微調強化隱性情感操控與複雜話術的偵測，並兼顧準確率與推理速度。

摘要

研究核心

針對隱性情感操控與複雜詐騙話術，開發高效且低延遲的偵測方案。

痛點

現代詐騙擅長利用情感需求（交友、戀愛）隱藏關鍵字，傳統技術難以捕捉非結構化的語境。

任務

延續「騙局雷達（TF-IDF + One-Class SVM）」，以 LLM 微調提升偵測深度並優化運算成本。

期望成效

準確率 >95%、推理延遲 <2 秒，開發高效低成本的檢測方案，並作為資安領域的技術參考。

研究階段

Phase 1

指標設計與模型篩選

制定準確率、召回率、推理速度等核心指標，挑選適合詐騙檢測的 LLM 進行性能比較。

Phase 2

客製化模型開發

對選定的 LLM 進行微調，使其能更有效地檢測特定詐騙情境中的關鍵字與情感特徵。

Phase 3

性能測試與比較分析

比較 LLM 與傳統 ML 在準確率、召回率、速度與資源消耗上的表現，驗證 LLM 能否識別非結構化語境中的隱性詐騙話術。

文獻探討與方法設計

3.1

LLM 選擇與應用

選擇 LLM 時需兼顧有效性、效率與工作流程整合（Li et al., 2024）；不同模型在欺詐檢測表現相近，但在語用推理等任務上差異顯著（Chakraborty, 2024）。

依 Han et al.（2024），LLM 可分三類：

  1. 通用 LLM（GPT-4、Claude 2）— 能力強、成本高，適合雲端 API。
  2. 輕量級 LLM（Llama 3 8B、GPT-3.5）— 可本地部署，兼顧準確率與成本。
  3. 專門 NLP 模型（BERT、RoBERTa）— 微調後適合即時詐騙文本檢測。

挑選關鍵指標

性能
參數量、token 上限與推理能力決定複雜任務的處理上限（Han et al., 2024）。
準確度
詐騙檢測目標準確率須 >95%，以確保實務可靠性（Yoon, 2023）。
推理速度
GPT-4 約 2–5 秒；Llama 3 8B 約 1–2 秒，但準確率可能略低（Han et al., 2024）。
3.2

資源需求與本地運行

雲端 LLM（GPT-4、Claude 3）依 token 計價，適合快速驗證但長期成本與隱私需考量；本地模型（Mistral 7B、Llama 3 8B）經量化可在消費級 GPU 運行，大型模型則需 A100 / H100。

  • 短期測試優先雲端 API，快速取得結果。
  • 長期部署評估本地 LLM 與輕量化技術，降低 API 成本。
  • 即時 vs 批次即時防詐偏雲端；大量歷史資料分析偏本地。
3.3

LLM 微調與情緒分析的結合

詐騙話術常結合情緒操控（恐懼、緊迫、信任誘導），傳統 ML 難以捕捉語境特徵；BERT + TF-IDF 可強化中文文本分類（Sun, Bao & Bu, 2022）。處理長文本需 chunking，即時系統則重視回應速度（Han et al., 2024）。

微調採 LoRA / PEFT 降低計算成本（Han et al., 2024）。ML 在領域關鍵字上仍有優勢，LLM 則在語境理解與隱性詐騙檢測上更具適應性（陳恩齊, 2019; Papasavva, 2024）。

研究方法及步驟

4.1 研究方法

優先以雲端 LLM 快速驗證，中期評估本地部署；以實驗法比較不同訓練方式，找出情感操控偵測的最佳方案。

4.1.2 Low-Rank Adaptation

以低秩分解微調少量參數，降低成本並保持推理能力，適用於 GPT、LLaMA、BERT。

4.1.3 ROUGE 指標

衡量生成文本與參考答案的重疊程度，用於評估 NLG 與摘要品質。

4.2 研究步驟

資料來源含警政署詐騙案例、165 反詐網站與 Chinese SMS Spam Dataset；以人工標註、TF-IDF 與 BertTokenizer 建立並預處理詐騙語料。

01文獻調查與初步分析

蒐集詐騙檢測相關文獻與技術資料，總結現有方法的優缺點，確認研究方向與目標。

02數據蒐集與預處理

建立研究所需的詐騙文本數據集，完成數據過濾與標註，並對文本進行分塊（Chunking）處理，確保適配 LLM 的上下文需求。

03模型性能比較與指標設計

制定準確率、召回率、延遲與資源消耗等指標；比較 GPT-4、LLaMA 2、Mistral 7B 與「騙局雷達」ML 模型（TF-IDF + One-Class SVM）在關鍵字與情感操控偵測上的表現。

04搭建雲端模型與微調

導入資料集並設計 prompts，以 LoRA 微調（約省 80% 計算成本），搭配 ROUGE 評估。微調策略包含：情緒標註 SFT（BERT-Base-Chinese）、LoRA 高效微調、情緒向量嵌入（Sun, Bao & Bu, 2022）。

05模型測試與性能比較

測試 LLM 與 ML 模型在不同數據集上的表現，記錄準確率、召回率、推理速度等指標。比較微調前後的性能差異，分析 LLM 與 ML 的效能優劣。

06建置本地端及考量風險

指標達標則評估本地部署；未達標則改為預訓練 LLM + TF-IDF 規則篩選，或縮減 API 測試規模。

07實驗與測試

在不同數據集上測試優化後的 LLM 模型與現有 ML 模型，評估其在準確率、召回率與推理速度等指標上的表現。分析 LLM 與 ML 的資源消耗，權衡其應用於實際場景的可行性。

08撰寫報告與成果總結

整理研究過程與結果，完成結案報告，並對未來研究方向與應用場景提出建議。

預期結果

平衡效率與準確度

以 LLM 微調縮短開發時間，並透過 prompt 設計提升準確率。

降低模型參數量

找出效能與參數量的最佳平衡，降低運行成本並維持低延遲。

持續優化模型

隨詐騙手法演進持續微調，協助政府與民眾強化防詐辨識。

與其他單位合作

與企業、學校及警政單位合作，將技術融入防釣魚與資安教育場景。

期望發表

成果預計發表於台灣學術研討會，分享 LLM 與傳統 ML 在詐騙偵測上的實務應用。
