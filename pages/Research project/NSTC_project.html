大型語言模型應用在詐騙偵測之研究

探討 LLM 在語意理解與情緒操控辨識上的應用效果；系統性比較 6 種模型，並提出可本地部署的 Emotion-LoRA 架構。

研究者：徐子崴

研究摘要

本研究針對台灣日益嚴重的詐騙問題，特別是投資、交友與情緒操控型話術，比較傳統機器學習與大型語言模型在詐騙偵測上的效能差異。實驗顯示，以 TF-IDF + Logistic Regression 為基線的傳統方法準確率僅 48%，幾乎將多數訊息誤判為詐騙；而 Gemini 2.5 Pro 與自研的 Emotion-LoRA 均可達 94% 準確率與 100% 召回率。

  • 6 種 模型對照
  • Emotion-LoRA 情緒條件化微調
  • 0.24 秒 即時推論

研究背景與動機

詐騙現況

  • 2024 年詐騙案件較前一年增加 15%
  • 投資詐騙佔整體案件 35%
  • 交友詐騙 28%、假冒身分 22%

傳統方法侷限

  • 關鍵字比對準確率僅 48%
  • 情緒操控型詐騙辨識率 32%
  • 難以應對無明顯關鍵字的隱性話術

研究動機

延續「騙局雷達」對詐騙關鍵字的探索，進一步驗證 LLM 是否能在語意理解與情緒維度上補足傳統 ML 的不足，並評估雲端 API 與本地端 LoRA 模型在準確率、延遲與成本上的實務可行性。

研究問題與發現

RQ1

LLM 是否優於傳統 ML？

比較準確率、召回率與 F1-score。Gemini 2.5 Pro 與 Emotion-LoRA 表現最佳，準確率 94%、召回率 100%。

RQ2

能否辨識隱性詐騙？

關鍵字型詐騙辨識率 95%；隱性語境詐騙僅 72%。Emotion-LoRA 語境理解達 94%，情緒操控型辨識提升至 88%。

RQ3

本地端 LoRA 是否可行？

Qwen2.5-1.5B + LoRA 準確率 89%；Emotion-LoRA 推論僅 0.24 秒，具即時防詐部署潛力。

RQ4

情緒條件是否有效？

分析 greed、urgency、fear、trust 四類情緒操控。加入情緒條件後，隱性詐騙辨識提升 16%，整體辨識率提升 22%。

資料集與研究方法

354 總筆數
180 詐騙訊息
174 非詐騙訊息
51:49 正負類比例

標註欄位

  • 是否詐騙
  • 語意類型
  • 情緒操控
  • 情緒類型
  • 時間戳記
  • 發送者

研究流程

資料預處理 → 特徵提取 → 模型訓練 → 模型評估

評估指標：Accuracy、Recall、F1-score、AUC、Specificity

語意與情緒分析

Keyword vs Implicit

  • 關鍵字型辨識率 95%
  • 隱性型辨識率 72%（傳統模型易漏判）
  • 加入情緒條件後，情緒操控型提升至 88%（+16%）
  • Emotion-LoRA 語境理解達 94%

詐騙情緒類型分佈

  • Greed 貪婪35%
  • Urgency 緊迫28%
  • Fear 恐懼22%
  • Trust 信任15%

在緊迫感與信任建立類話術中，情緒條件化模型表現尤佳。

成本與部署分析

模型 平均延遲 吞吐量 成本 / 千次 部署建議
Gemini 2.5 Pro 10.79 s 0.09 req/s $2.50 準確高、延遲長
Mistral Large 2.17 s 0.46 req/s $1.80 中等
Qwen + LoRA 0.67 s 1.49 req/s $0.05 快速
Emotion-LoRA 0.24 s 4.17 req/s $0.03 即時防詐首選

雲端模型準確率高但延遲長，不適合即時應用；Emotion-LoRA 以 Qwen2.5-1.5B 為基礎，成本較雲端降低約 90%，兼具準確率與推論速度。

結論與貢獻

+46% 準確率提升
100% 召回率
0.24s 本地推論
-90% 部署成本

實驗證實 LLM 在詐騙偵測上全面優於傳統 ML，而 Emotion-LoRA 在維持高準確率的同時，具備即時部署的實務可行性。

研究結論

01

LLM 優於傳統 ML

準確率由 48% 提升至 94%，相對提升 46%。Baseline 幾乎將所有訊息誤判為詐騙，LLM 則能掌握語意脈絡。

02

情緒條件化有效

隱性詐騙辨識提升 16%，召回率達 100%。

03

LoRA 降低部署成本

小型本地端模型接近雲端大型模型效果，成本降低約 90%。

04

本地端具實務可行性

Emotion-LoRA 推論僅 0.24 秒、每秒 4.17 次請求，適合即時防詐；參考架構為 Qwen2.5-1.5B + Emotion-LoRA。

學術貢獻

  1. 情緒條件化架構

    創新將情緒訊號融入詐騙偵測，強化隱性話術辨識。

  2. 系統性模型比較

    全面對照雲端與本地端 LLM 的效能、延遲與成本。

  3. 語意與情緒分析

    揭示情緒維度對模型行為的關鍵影響。

  4. 可部署參考設計

    提供可落地的本地端防詐方案與實作路徑。
