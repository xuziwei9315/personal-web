騙局雷達

透過 AI 情感分析與自然語言處理，防範沉浸對話式詐騙，並以網頁爬蟲辨識可疑網站，協助民眾守住財產。

  • 專題發表優秀組別
×

核心概念

系統定期提供常見反詐騙資訊、詐騙類型及實際案例，供使用者閱覽，加強媒體識讀及防範詐騙的意識。

在與詐騙的相似度辨識上，設立了兩道防線：第一道串接內政部警政署 165 接獲之 LINE ID 及網址；第二道進行 AI 情感分析與自然語言處理分詞，再進行詐騙及非詐騙關鍵字的相似度百分比辨識。由於現代民眾防詐意識較高，詐騙集團可能避開常見關鍵字行騙，此時透過訓練模型判斷，可大幅降低受騙機率。網站部分則透過爬蟲讀取內容是否含有詐騙資訊；若檢測有誤差，使用者可利用回報功能修正，也能主動提供資料擴充系統。

使用者進行防詐檢測的同時，系統會記錄檢測資料，統計類型及關鍵字的檢測次數，讓使用者得知目前哪種詐騙類型較為常見。

兩道防線

第一道防線｜官方資料比對

串接內政部警政署 165 通報之 LINE ID 與網址清單，快速比對使用者輸入內容是否命中已知詐騙來源。

第二道防線｜AI 語意分析

結合 AI 情感分析、自然語言處理分詞與關鍵字相似度辨識；當詐騙話術避開常見字眼時，由訓練模型輔助判斷，並以爬蟲分析網站內容。

使用者介面

從防詐知識建立、多模態內容檢測，到回報迭代與趨勢洞察，最後以情境演練強化實戰意識——完整覆蓋一般使用者的防詐旅程。

防詐知識

提供相關資訊

瀏覽「常見手法」與「時事詐騙新聞」，了解詐騙類型與關鍵字，強化防詐觀念。

多元檢測引擎
核心能力

AI 情感分析與 NLP

面對情境化、避開關鍵字的詐騙話術，進行更進階的語意與情緒判斷，補足傳統關鍵字比對的盲區。

關鍵字比對

結合詐騙關鍵字資料集與政府公開資料，比對使用者上傳文字，辨別是否為詐騙內容。

網站爬蟲

讀取使用者貼上之網址內容，並結合政府「假博弈網址」資料集過濾，減少人工比對時間。

圖片文字辨識

辨識圖片中夾雜的文字訊息，因應詐騙集團以圖片傳遞資訊的手法。

檔案文字辨識

從檔案內容擷取文字進行分析，涵蓋以檔案傳遞的詐騙訊息。

回饋與洞察

準確度回報

使用者可回報誤判樣本，協助管理者修正模型、補強漏洞。

資料提供及回報

擴充系統關鍵字資料庫，從使用者回報中持續提升檢測準確度。

統計資料

記錄檢測結果並統計類型與關鍵字次數，呈現當前常見詐騙趨勢。

情境演練

情境對話小遊戲

沉浸式對話練習，找出關鍵詐騙引誘句並提供解析與分數，在互動中提升反詐意識與判斷力。

  • 進入情境
  • 辨識話術
  • 獲得解析
  • 累積分數

管理者介面

  • 資料集更新一鍵上傳檔案更新訓練資料，依實際詐騙趨勢即時補充樣本，提升模型準確性。
  • 檢測紀錄查閱查閱所有使用者歷史檢測紀錄，掌握最新詐騙樣態並更新關鍵字資料集。
  • 回報樣本管理彙整使用者回報的可疑訊息，進行人工檢測、編輯或刪除，並將新關鍵字納入訓練集。

運用的技術

機器學習

採用半監督式學習，以少量已標記資料訓練分類模型，並隨使用者回報持續強化，辨別輸入內容是否為詐騙。

網路爬蟲

依規則自動擷取網站文字與圖片連結，搭配政府開放資料擴充樣本，減少人工收集時間。

圖片辨識

使用 PaddleOCR PP-OCR，依序進行文字檢測、框體校正與識別，將圖中文字轉為可分析的純文字。

情感分析

結合 NLP 與情緒檢測，辨識詐騙話術中的情緒操控類型，作為相似度判斷的輔助指標。

辨識流程

輸入判斷 → 爬蟲 / OCR → 165 黑名單 → BERT 相似度 → 情緒分析 → 關鍵字萃取
  1. 01

    輸入判斷與爬蟲預處理

    根據使用者上傳類型（文字、網址、圖片、檔案）進行分流處理。若為網址，先以爬蟲取得網頁中的文字內容及圖片連結，以防詐騙者將詐騙訊息藏在網頁圖片或內文中；若為文字則直接進入後續辨識流程。

    • Python Flask
    • BeautifulSoup
    • Web Scraping
  2. 02

    PaddleOCR 影像文字辨識

    對爬蟲取得的網頁圖片連結，以及使用者直接上傳的圖片或檔案，使用 PaddleOCR PP-OCRv3 進行高精度文字辨識，將圖中文字提取為可供後續 NLP 模型處理的純文字。

    • PaddleOCR
    • PP-OCRv3
    • Image Processing
  3. 03

    警政署 165 API 黑名單比對

    將辨識內容中的 LINE ID 及網址與警政署 165 接獲並公開的詐騙黑名單 API 進行即時比對。若命中黑名單，直接向使用者回報「此內容已被政府認定為詐騙」，無需進入後續 AI 辨識流程。

    • 165 API
    • REST API
    • Blacklist Matching
  4. 04

    BERT 詐騙相似度辨識

    以自行收集的詐騙關鍵字語料庫對 BERT 進行 Fine-tuning，並在頂層加入分類層。辨識時，輸入文字經 BERT 產生特徵向量，傳入分類層得到 logits，轉換為 0–100% 的詐騙相似度百分比呈現給使用者。

    • BERT
    • Fine-tuning
    • PyTorch
    • Classification Layer
    • TF-IDF
  5. 05

    情緒分析與角色辨識

    將辨識文字切分為單句後，以第二個 Fine-tuned BERT 對每句進行角色辨識（詐騙者/受害者），再使用 HuggingFace 上的中文情緒分析模型對各句評分，找出整段對話中情緒強度最高的句子，作為情緒操控指標回饋給使用者。

    • HuggingFace
    • Sentiment Analysis
    • Role Classification
    • BERT
  6. 06

    關鍵字萃取與詐騙類型判定

    先以資料庫中的詐騙關鍵字清單進行比對；若無命中，則呼叫 Gemini API 及第三個 BERT 模型協同萃取內容中的詐騙關鍵字與詐騙類型，最終將相似度、風險等級、詐騙類型、關鍵字與防範建議整合輸出。

    • Gemini API
    • BERT
    • Firebase
    • Keyword Extraction
